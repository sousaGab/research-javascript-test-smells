# Copilot project policy

- Never add Co-authored-by or Co-Authored-By trailers in commit messages.
- Never attribute commits to any LLM assistant, including Claude, Copilot, ChatGPT, Gemini, DeepSeek, OpenAI, Anthropic, or other AI agents.
- All commits must reflect human authorship only.
- If a prior history already contains AI co-author trailers, rewrite the git history to remove them before pushing.
